Before You Upload

A few quick reminders help improve cleaning accuracy and reduce review delays.

1. Use Clear Titles Name files so reviewers understand the context

Include the batch, department, or reporting period whenever possible.

2. Add Short Context Describe what the dataset contains

A short description helps the cleaning review stay aligned with the academic purpose of the file.

3. Choose Cleaning Rules Select only the checks you want applied

This keeps the processing flow predictable and easier to validate after cleaning.

Recommended file content

  • Academic spreadsheets with stable headers and clear field names.
  • Attendance, registration, result, or student profile exports.
  • Files that match a single reporting purpose or workflow.
  • Datasets small enough to review clearly after cleaning.
